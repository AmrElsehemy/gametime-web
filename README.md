# Game Time Web

Public web presence for **Knowlly Games**.

This repository is primarily the **marketing / portfolio / support / legal website** for `knowlly.games`.

## Initial scope

- studio homepage
- game catalogue
- individual game landing pages
- App Store links / QR codes
- privacy policy
- terms
- support/contact
- press/media assets

## Not the backend

Operational APIs, remote configuration and kill switches belong in `gametime-backend`.

A lightweight authenticated `/admin` surface may be added here later if a browser UI is useful for operating the backend, but it is not required for v1.

## Deployment

Target: Next.js on Vercel.
